# VettedAI Claude Code Plugin

Work your [VettedAI](https://www.vettedai.app) recruiting pipeline — candidates, projects, sourcing, auditions — directly from [Claude Code](https://claude.com/claude-code), without leaving your editor.

## Install

```
/plugin marketplace add Generous-Circle/vettedai-claude-plugin
/plugin install vettedai@vettedai-claude-plugin
```

On first use, Claude Code opens a VettedAI sign-in and consent screen. Approve it once — after that, every tool call runs scoped to your own VettedAI account (your candidates, your projects, nobody else's).

## What you can do

- See your top candidates for any role
- Check a project's pipeline status
- Draft a new role from a job description
- Send an audition invite to a candidate
- Search and screen sourced candidates

Full tool reference: [vettedai.app/mcp/docs](https://www.vettedai.app/mcp/docs)

## Other ways to connect

VettedAI's MCP server also works with Claude.ai, ChatGPT, Codex, and opencode — see [vettedai.app/mcp/setup](https://www.vettedai.app/mcp/setup) for those.
